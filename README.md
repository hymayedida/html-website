# 🌐 GitHub Pages Static Website

This is a simple static website hosted using **GitHub Pages** as part of a DevOps internship task.

## 🚀 Live Website

Click here to view the live website:  
https://hymayedida.github.io/html-website/

 📁 Project Structure
 .
├── index.html # Main HTML file
├── style.css # Optional: CSS styling (if added)
└── README.md # Project documentation


## 🛠️ How It Works

1. Created a basic `index.html` file
2. Pushed it to a public GitHub repository
3. Enabled **GitHub Pages** in the repository settings
4. Selected the `main` branch and root directory `/`
5. Website is now live using GitHub Pages!
